  5. Entra al radio por su nueva IP (101–250): pon la IP, abre su web y copia el token.

❓ Ayuda paso a paso

1 · Abrir el ayudante (una vez al empezar)

  1. Primera vez: instala Python desde python.org y marca Add Python to PATH.
  2. Abre la carpeta donde está ligo_helper.py, haz clic en la barra de la ruta, escribe cmd y presiona Enter.
  3. En la ventana negra escribe y presiona Enter:python ligo_helper.py
  4. Debe decir "Ayudante listo". Déjala abierta. Arriba, la app debe mostrar En línea en verde.
Windows lo bloquea (Control inteligente de aplicaciones)

Opción A: abre PowerShell, pega esto, Enter, y repite el paso 1.3:

Unblock-File "$env:USERPROFILE\Downloads\ligo_helper.py"

Opción B (doble clic): Bloc de notas → pega esto → Guardar como → Tipo "Todos los archivos" → abrir_ayudante.bat → Escritorio. Dale doble clic. Si el archivo no está en Descargas, cambia esa ruta.

@echo off cd /d "%USERPROFILE%\Downloads" python ligo_helper.py pause

2 · En cada casa

  1. En Radios e IP cambia el último número con las flechas ▲ ▼ o escribiéndolo. Al cambiar de casa se borra el token anterior.
  2. Presiona ↗ Abrir interfaz web del radio e inicia sesión.
  3. En esa pestaña: F12 → Network → filtro Fetch/XHR → clic en una fila periodic → Headers → baja a Request headers → línea Cookie → copia todo el valor. Debe traer token=... y CSRF-TOKEN=....
  4. Vuelve a la app, presiona 📋 Pegar token y luego 🔌 Conectar.
  5. Al terminar presiona Logout en el radio.

3 · Si algo falla

  • "No encuentro el ayudante": ábrelo con el paso 1.
  • Error 10048 / "address already in use": ya estaba abierto. No abras otro.
  • Sesión expirada: copia el token de nuevo (paso 2.3).
  • No conecta: revisa que el token traiga token y CSRF-TOKEN.

4 · Perfiles del PC (administrador)

Para que los botones de Radio nuevo cambien la IP y el VLAN ID del PC, el ayudante debe abrirse como administrador: busca cmd en Inicio → clic derecho → Ejecutar como administrador, y escribe:

cd /d "%USERPROFILE%\Downloads" python ligo_helper.py

La ventana debe decir "administrador: sí". También sirve la opción 4 de herramientas_windows.bat.
